# Nexly
🎬 README — CineTech (Plateforme de streaming inspirée de Netflix)
📌 Description

CineTech est une plateforme de streaming de films et séries inspirée de Netflix.
Le projet vise à reproduire les fonctionnalités principales d’un service moderne de vidéo à la demande, avec une interface fluide et une architecture scalable.

🚀 Fonctionnalités
🎞️ Catalogue de films et séries
🔎 Barre de recherche
❤️ Système de favoris 
📊 Recommandations personnalisées (basées sur les vues)
